## Candidate 2 — Pre-unlock short (08b): **OVERTURNED** (the calendar exists, free and keyless)

Blocking claim: "no free/keyless historical token-unlock calendar exists" (DefiLlama 402, CMC
404, Tokenomist gated, unlocks.app shell, CryptoRank 404).

**Route-by-route re-verification (fresh calls, 2026-07-11): the screener's table is accurate as
far as it went.** `api.llama.fi/emissions` → HTTP 402 "Upgrade to the paid API plan" ✓;
`api.coinmarketcap.com/data-api/v3/token-unlock/latest` → HTML error shell ✓;
`api.cryptorank.io/v0/token-unlock/upcoming` → 404 NestJS error ✓.

**But the conclusion is falsified.** The same emissions dataset that the paywalled API fronts is
served keylessly from DefiLlama's public datasets bucket — the open data that powers
defillama.com/unlocks for anonymous browsers. Verified endpoints (all HTTP 200, no key, no
auth header, 2026-07-11):

1. **Protocol list:** `https://defillama-datasets.llama.fi/emissionsProtocolsList`
   → JSON array of **342 protocol slugs**.
2. **Per-protocol historical calendar:** `https://defillama-datasets.llama.fi/emissions/{slug}`
   → `metadata.events[]`: each event has `timestamp`, `noOfTokens`, `category`
   (mapped via top-level `categories` to insiders / privateSale / noncirculating / airdrop /
   staking), `unlockType` (`cliff` | `linear`), description. Also `documentedData` (daily
   unlocked-supply series per allocation label), `supplyMetrics` (maxSupply, adjustedSupply),
   `gecko_id` (join key), `unlockUsdChart`.
3. **Aggregate index:** `https://defillama-datasets.llama.fi/emissionsIndex`
   → per-token `circSupply`, `maxSupply`, events.

Coverage proof (my probes): **aptos** = 357 events from 2022-10-12; **arbitrum** = 111 events,
95 past, **89 cliff events inside the pre-registered 2023-06 → 2026-06 window**, with insider /
privateSale / noncirculating labels present. arbitrum/celestia/aptos all 200 — generality holds.

What the bucket does NOT hand over directly: the unlock-value/**mcap ratio** at event time. It
is derivable, not blocking: unlock value = `noOfTokens` × price (local 1h OHLCV); circulating
supply at event time reconstructible from the `documentedData` daily unlocked series (or gecko
history); ratio follows. This is screen-construction work, not a data gap.

**Consequence:** 08b's verdict INSUFFICIENT_DATA is overturned — the frozen pre-registration can
run as written (windows W1/W2/W3, 3%/12% capital-scaled template, funding charged to the short,
frozen gates). The sourcing protocol listed 5 routes and concluded from their failure; a 6th
route yields. The re-run must record the source swap (bucket endpoints above) in the screen doc;
no re-registration is needed since hypothesis/variants/gates/costs are untouched — only the
calendar's transport changed.

**Finding C2-a (HIGH, the overturn):** blocking gap does not exist; exact unblock =
`defillama-datasets.llama.fi/emissionsProtocolsList` + `/emissions/{slug}` (+ `/emissionsIndex`).
**Finding C2-b (INFO):** screener's negative results were each genuine — the failure was
stopping the search at the API host instead of asking "what feeds the public unlocks page?"

**Verdict: OVERTURNED.** The pipeline's most valuable candidate is unblocked at zero cost.
